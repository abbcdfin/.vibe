# Architectural Principles

Read and apply `reference.md` alongside this file. It owns the seven standards and
their trade-offs. Use `agile-principles` for sequencing and verification, and add
`agentic-principles` when the system being designed uses LLM reasoning and tools.

Principle names:

1. One Fact, One Place
2. Auto Propagation
3. Construct Engine
4. Building is Part of Architecture
5. Design for Scale
6. Minimal Mechanism
7. Resist Entropy
